# sshgo 产品愿景

## 愿景

sshgo 是一个**现代、安全、易用的 SSH 连接管理器**，通过 TUI 和 CLI 双模式管理服务器连接，支持密码、密钥、MFA 认证和嵌套跳转主机。

## 目标

- **零配置快速连接** — `sshgo <alias>` 一键登录，无需记忆 IP/密码
- **全键盘操作 TUI** — 无需鼠标即可浏览、搜索、管理主机和分组
- **安全认证** — 支持密码加密、MFA/TOTP、SSH Agent 集成
- **配置与运行时数据分离** — 配置文件不被登录历史等临时数据污染
- **启动审计** — 记录连接和传输启动事件, 为个人排查和轻量审计提供线索
- **多语言** — 支持中英文切换

## 非目标

- 不替代标准 SSH 客户端（如 OpenSSH、PuTTY）
- 不提供图形化 GUI（保持 TUI 轻量）
- 不提供远程桌面或 VNC 支持
- 不内置 CI/CD 流水线或自动化部署
